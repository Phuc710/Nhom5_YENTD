Đặt ảnh .jpg hoặc .png vào đây.
File nhãn tương ứng đặt vào: dataset/labels/train/<tên_ảnh>.txt

Format nhãn YOLO (mỗi dòng = 1 vật thể):
<class_id> <cx> <cy> <width> <height>
Tất cả giá trị cx/cy/width/height đều được chuẩn hóa về [0, 1]

Class IDs:
  0: motorbike
  1: car
  2: truck
  3: bus
  4: traffic_light_red
  5: traffic_light_yellow
  6: traffic_light_green
