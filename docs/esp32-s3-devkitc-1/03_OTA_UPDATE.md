# 03 - OTA Update

OTA không phải luồng trọng tâm của firmware stream-first hiện tại.

Nếu dùng lại OTA:

- ThingsBoard điều phối version/url
- firmware tải và cập nhật
- backend chỉ cần hiển thị trạng thái/version liên quan
